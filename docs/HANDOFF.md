## 📌 บทเรียนสำคัญ (อย่าลืมในแชทหน้า)

1. **"เกมอัปเดต" ≠ "selector เปลี่ยน"** — คราวนี้ DOM เหมือนเดิมเป๊ะ เปลี่ยนแค่ *จังหวะเรนเดอร์*
   ถ้าเชื่อข้อสรุปแรกแล้วรื้อ `shopTab`/`shopRows` = แก้ผิดจุด + พังของที่ดีอยู่แล้ว
   ⇒ **ก่อนสรุปว่า UI พัง ให้วัด "เวลา" ด้วย ไม่ใช่ดูแต่ "หน้าตา"**
2. **`sleep(N)` ตายตัว = หนี้ที่รอวันระเบิด** — เกมเร็ว/ช้าขึ้นนิดเดียวก็พัง · ที่ถูกคือรอ **เงื่อนไข**
   ⇒ ถ้าเจอ `await sleep(...)` ตามด้วยการอ่าน DOM ที่ไหนอีก ให้สงสัยไว้ก่อน
3. **เทสต์จับได้ในสิ่งที่ตาอ่าน diff มองข้าม** — `test-v6409.js` ฟ้องว่ามีจุดเรียกแท็บยา **อีก 4 จุด**
   ที่ผมแก้ไม่ครบ ([[tokpla-verify-means-run-not-read]])
