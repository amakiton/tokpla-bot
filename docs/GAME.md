## สูตรคะแนน (ใช้เล็งเข็ม)

| เฟส | เงื่อนไข | คะแนน | ค่าคงที่ในบอท |
|---|---|---|---|
| เกจตวัด (cast) | diff ≤ 0.09 | `100 − diff/0.09×40` → 60–100 | `CAST_SPAN=.09, CAST_DROP=40` |
| ดึงปลา (reel) | diff ≤ 0.0165 | 100 ทันที (โซนแดง) | — |
| ดึงปลา (reel) | diff ≤ 0.11 | `100 − diff/0.11×30` → 70–95 | `REEL_SPAN=.11, REEL_DROP=30` |

⚠️ reel ไม่มีคะแนน 96–99 จริง (กระโดด 95→100) — `scoreToOffset` เล็งกลางเมื่อ score>95

## สูตรผลลัพธ์ปลา

- `g = score/100`
- โอกาสขยะ: `junk = max(0.03, 0.30 − g×0.27)` — คะแนนสูง = ขยะน้อย
- ตัวคูณโชค: `m = g²×1.5 + baitBonus + rod + outfit + potion` — **ครอบงำโดย g** (ที่ 96–100 ≈ 1.44) · baitBonus แค่ 0.02→0.33
- ราคา: `price = base × (1 + 0.5×weightFrac)` · shiny ✨ = ×10
- เกม auto-fish ของเกมเองใช้คะแนนแย่โดยเจตนา (10–45) → บอทเรากำไร ~2 เท่า

> ⛔ **ข้อสรุปเดิม "เหยื่อถูกมักคุ้มกว่า" ตายแล้วตั้งแต่แพตช์ 29/7/2026** — ตอนนั้นราคาเหยื่อพุ่งชัน (5→450 = ×90)
> ตอนนี้ราคาขึ้นแบบเชิงเส้น (25→320 = ×12.8) แต่ `baitTailMult` คูณโอกาสปลาแพงถึง ×6 **และ** `baitRarityCeiling` ปลดเพดานระดับปลา
> ⇒ **ยิ่งขั้นสูงยิ่งคุ้มเสมอ** ดูสูตร + ตารางกำไร/ชม. ด้านล่าง

### 🎯 เข้าถึง Phaser game + ผลตก ผ่าน React state (v6.83 — กุญแจสำคัญ)

## 👹 ระบบล่าบอส + เดินแมพ (v6.103 — สำรวจสดยืนยัน)

**เข้าถึงผ่าน `getPhaserScene()` (fiber เดิม v6.83):**
```js
scene.mapManager.def.id           // 'boss_cave' | 'village' | 'river_bank' | 'fisher_town' | ...
scene.mapManager.def.zones        // [{type:'exit'|'spawn'|'fishing', id, name, x, y, width, height, targetMap, targetSpawn, fishPoolId, castRadius}]
scene.mapManager.def.width/height // ขนาดแมพ (px)
scene.player.x / .y               // ตำแหน่งตัวละคร (อ่านสด) · .setPosition(x,y) มีแต่ไม่ trigger transition
scene.player.wasd / .cursors      // Phaser Key objects (W/A/S/D + ลูกศร) — ตอบ synthetic keydown
scene.raidBoss                    // {hidden, dead, destroyed, phase, x, y, image, ...} · hidden=true ตอนบอสยังไม่มา
scene.playerHp / .playerHpMax     // HP ผู้เล่น (บอสตีได้) · bossAttackUntil
scene.spawnRaidBoss/startBiteDodge/startSpinDodge/showAttackTelegraph/showSpinTelegraph  // = มีท่าโจมตีให้หลบ
```
- **เวลาบอส (DOM · ทุกแมพ):** text node ใน `span.tabular-nums` ใน chip `tk-chip` (chip ขึ้นต้น `👹`) · หัวข้อ "👹 <ชื่อบอส>จะโผล่รอบถัดไป" · ไม่ต้องรู้คาบ ~5 ชม. เกมบอกตรง
  - ⚠️ **2 รูปแบบ (ยืนยันสด v6.106) — พลาดข้อนี้ทำระบบล่าบอสตายสนิท:**
    - เหลือ **≥ 1 ชม.** → `บอสถัดไป 16:30 (อีก 1 ชม. 27 นาที)`
    - เหลือ **< 1 ชม.** → `บอสถัดไป 16:30 (อีก 2:20)` = **MM:SS** (วัดสด 51 วิ: 2:20→1:30 = ลด 1/วินาที)
  - `bossLeadMin` ~5 นาที ⇒ บอทอ่านค่าใน**ช่วง MM:SS เสมอ** → ต้อง parse ทั้งคู่
  - อ่านค่าตอนแท็บซ่อน = **ค่านิ่ง** (เกม rAF หยุด) — อย่าใช้สรุปหน่วยเวลา
- **ปุ่มตีบอส:** orb `button[aria-label="ตีบอส"]` (class `tk-orb`) — `disabled` ตอนไม่มีบอส (เหมือน orb "ตกปลา (F)")
- **เดินเปลี่ยนแมพ (พิสูจน์สด):** `W.dispatchEvent(new KeyboardEvent('keydown',{code:'KeyD',keyCode:68,...}))` ค้าง → ตัวเดินขวา (~48px/150ms) → เดินเข้าโซน `type:'exit'` (x,y,w,h) → เกมเปลี่ยนแมพ + spawn ที่ targetSpawn · ปล่อยปุ่มด้วย keyup เสมอ
- **กราฟแมพ:** รู้ exit เฉพาะแมพที่อยู่ปัจจุบัน (`def.zones`) → เรียนรู้สะสมลง `tokpla_boss_graph` แล้ว BFS · village = hub (ต่อ river_bank/boss_cave/fisher_town/ice) · boss_cave ต่อ village อย่างเดียว
- zones ตัวอย่าง boss_cave: spawn `from_village`(836,800) · fishing `boss_pool`(841,445 castRadius560) · exit `to_village`(836,915 w240 h44 →village/from_boss_cave)

## ข้อจำกัดแพลตฟอร์ม

- ต้องมี `@grant` (unsafeWindow + GM_xmlhttpRequest) — `@grant none` โดน CSP ของ Vercel บล็อก
- Telegram ต้องผ่าน `GM_xmlhttpRequest` เท่านั้น (fetch โดน CSP)
- ยิง event ผ่าน `unsafeWindow` (W) ไม่งั้น React ไม่ได้ยิน
- เกมเด้ง "พักจอนาน 5 นาที" เมื่อ `document.hidden` นาน → บอท override เป็น false ตลอด (`keepTabAlive`)
